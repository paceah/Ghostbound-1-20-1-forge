# Границы защиты Ghostbound

Исследованы локальные исходники `forge-1.20.1-47.4.28_mapped_official_1.20.1-sources.jar`, Mojang mappings 1.20.1. Несуществующие отменяемые события не используются. Все Mixin обязательные с `defaultRequire=1`: несовместимое изменение целевого кода должно останавливать загрузку, а не незаметно отключать запрет.

| Ограничение | Серверная точка | Проверка |
|---|---|---|
| Ванильный TP | HEAD `ServerGamePacketListenerImpl.handleTeleportToEntityPacket`, повторяет `PacketUtils.ensureRunningOnSameThread` перед чтением состояния | GameTest вызывает настоящий обработчик пакета, отдельно нужна проверка изменённого клиента |
| Камера по клику/атаке | Redirect `ServerPlayer.attack` → `setCamera` | GameTest атакует другого игрока, отдельно проверить мобов и визуальный результат |
| Ванильное меню | Redirect `ServerPlayer.openMenu` → `MenuProvider.createMenu` до `ClientboundOpenScreenPacket` и `initMenu` | GameTest проверяет отказ меню с внешними слотами |
| Forge menu | Redirect трёхаргументного `NetworkHooks.openScreen` → `MenuProvider.createMenu` до `playChannel.sendTo` | Исходники проверены, реальный сторонний контейнер не установлен |
| Лошади | HEAD `ServerPlayer.openHorseInventory` до пакета открытия | Требует игрового теста |
| Синхронизация и смена режима | HEAD `ServerPlayer.initMenu`, закрытие в HEAD `ServerPlayer.tick` до `broadcastChanges` | Дополнительные предохранители, не замена основным проверкам |
| Согласие | `RequestService.decide` на основном серверном потоке | UUID адресата, статус, deadline, режимы, подключение, здоровье, мир; удаление ID до reentrant teleport hooks |

Меню признаётся внешним, если оно не является стандартным `inventoryMenu` игрока и содержит хотя бы один слот с `slot.container != player.getInventory()`. Это покрывает стандартные слоты и Forge `SlotItemHandler`, а также оставляет доступными стандартный собственный инвентарь и меню без внешних слотов. Созданное запрещённое меню получает `removed`, не подключается к синхронизатору и не отправляется клиенту через стандартный путь. Конструктор меню вызывается для классификации, поэтому сторонние конструкторы обязаны соблюдать стандартный контракт без самостоятельной рассылки секретных данных.

Абсолютной защиты произвольных модов нет. Мод может передавать предметы/GUI собственными пакетами, рассылать информацию в `createMenu` или `extraDataWriter`, самостоятельно устанавливать синхронизатор, скрывать внешние данные под контейнером игрока или вообще не использовать слоты. Эти пути требуют интеграций с конкретным модом. `initMenu` блокирует штатную передачу слотов, но не отзывает информацию, которую другой мод уже отправил. Ни один сторонний контейнер пока не проверен в игре. Неслотовые интерфейсы с собственными данными не классифицируются как внешние слоты.

Административный `/spectate` не перехватывается, поскольку ТЗ сохраняет административные команды. Перехват ограничен spectator-атакой, а не глобальным `setCamera`. `/tp`, сторонние `/tpa` и любые самостоятельные модовые переносы тоже не перехватываются. Свободный no-clip полёт разрешён. OP не имеет исключения в перехваченных действиях.

Клавиша использует существующий ванильный транспорт команды, пользовательских пакетов нет. Сервер получает отправителя из `CommandSourceStack`, никаких передаваемых UUID отправителя, координат или флага разрешения не принимает. ID решений разбирает Brigadier `UuidArgument`. При обработке ID постороннего лица состояние не меняется. Операторы с правом `execute as` по-прежнему обладают административными полномочиями; это не ограничитель действий администратора сервера.

Чат использует `translatableWithFallback`: клиент с ресурсами мода выбирает RU/EN, клиент без мода читает английский fallback, включая кнопки и hover. Сервер не может установить язык неизвестного клиента или доставить ему RU-ресурсы без установки мода/ресурспака. Собственного канала, обязательного handshake и ручных библиотек нет. Подключение обычного клиента всё ещё требует проверки T40, особенно вместе с другими модами, которые могут требовать Forge-клиент.

SavedData сохраняется штатными autosave/shutdown Minecraft. Аварийное завершение процесса до записи мира может потерять недавние изменения, как и другие SavedData. Перед плановым рестартом используйте штатную остановку. Файл имеет Version=1 и валидирует обязательные UUID и длительность pending-записей; ручное редактирование NBT не является поддержанным способом настройки.

Релизный JAR содержит SRG refmap из локальной таблицы ForgeGradle. Для userdev запуска refmap отключён в Gradle run properties, поскольку классы используют Mojang-имена. Проверка запуска готового reobfuscated JAR на отдельно установленном Forge-сервере остаётся отдельной обязательной приёмкой.
