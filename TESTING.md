# Проверки Ghostbound

Среда: Windows, Java 17.0.21, Minecraft 1.20.1, Forge 47.4.28, Gradle wrapper 8.8

Матрица ниже описывает полную игровую приёмку из ТЗ. NOT TESTED означает, что сценарий не был полностью воспроизведён на двух настоящих клиентах. Статическая проверка и серверные тестовые игроки не заменяют такой прогон

Подготовка: отдельный мир и два клиента A/B, при необходимости третий C; B онлайн в Survival, A первоначально Spectator; стандартные значения конфига 60/600/3/3; между независимыми сценариями сбрасывайте тестовый мир или ожидайте сроки. Изменения конфига проверяйте после перезапуска. Для читерских пакетов используйте отдельный тестовый клиент, а не боевой сервер

Автотест: `.\gradlew.bat runGameTestServer`, исходник `GhostboundTests.java`; запускается на настоящем логическом dedicated-сервере с двумя серверными игроками и embedded Netty каналами, без графических клиентов. Проверяет отказ для Survival/Adventure/Creative, self/offline, duplicate, чужое подтверждение, смену режима, 60-секундный deadline, 600-секундный penalty, NBT roundtrip, запрет TP-пакета, камеру, внешнее меню, согласие и replay. Время ожидания 60/600 секунд этим тестом не воспроизводится, проверяются вычисленные сервером deadlines

## Команды и результаты

- `gradlew.bat build`, этап A: BUILD SUCCESSFUL
- `gradlew.bat build`, этап B/C: BUILD SUCCESSFUL
- `gradlew.bat build`, этап D/E/F: BUILD SUCCESSFUL после исправления генерации SRG refmap
- `gradlew.bat runServer`: остановился на требовании принять EULA, игровой мир не запущен
- Итоговый `gradlew.bat runGameTestServer build`: все проверки объединённого GameTest прошли, `All 1 required tests passed`, итоговая сборка BUILD SUCCESSFUL в `final-validation.log`
- GameTest также проверил независимое выключение трёх запретов, границы expiry/cooldown, камеру свиньи и синтетическое Forge NetworkHooks меню; пакеты OpenScreen/ContainerSetContent/ContainerSetSlot при заблокированном открытии не отправились
- `runClient`: после исправления dev refmap клиент загрузил мод, зарегистрировал ресурсы, создал атласы текстур без ошибок Mixin; процесс завершён нами после smoke-проверки, поэтому Gradle сообщает ненулевой exit code, это не успешное штатное закрытие клиента; визуальный Controls/P, переводы и подключение не проверены
- RU/EN JSON разобраны, набор из 24 ключей совпадает, в пользовательских строках нет длинных тире и точек; это статическая проверка, не PASS T47
- Проверен состав JAR: metadata ghostbound 1.0.0, обязательные Mixin и SRG refmap, обе локализации; тестовые классы и шаблон исключены

## Изменённые и добавленные файлы

- `command/SpectatorCommands.java`, `service/RequestService.java`, `persistence/RequestSavedData.java`: команды, согласие, перенос, сроки, сохранение
- `message/Messages.java`, `message/English.java`, `assets/ghostbound/lang/{en_us,ru_ru}.json`: сообщения с английским vanilla fallback и переводы
- `client/ClientKeyBindings.java`: опциональная клавиша P
- `protection/SpectatorProtection.java`, `mixin/{SpectatorPacketMixin,ServerPlayerMixin,NetworkHooksMixin}.java`, `ghostbound.mixins.json`: обязательные серверные перехваты
- `gametest/GhostboundTests.java`, `data/ghostbound/structures/empty.nbt`: тестовая среда, исключена из релизного JAR
- `README.md`, `TESTING.md`, `SECURITY_NOTES.md`, `config/ghostbound-server.toml`: документация и реальный образец автоконфига
